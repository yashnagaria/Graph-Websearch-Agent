# Project Overview

Graph Websearch Agent is a repository for building a web search and query execution workflow. The project uses search tools, graph processing, and configurable model options to answer user queries and automate search tasks.

## Contents

- `agent_graph/` — graph logic and node workflows.
- `app/` — main application and chat interface.
- `tools/` — web scraping and search integration utilities.
- `config/` — configuration templates and runtime settings.
- `README.md` — primary project instructions.
